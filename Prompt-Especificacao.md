Aplicação - Resolvedor de Equações do 2º Grau


Desenvolva uma aplicação que seja capaz de resolver equções de segundo grau: o Resolvedor de Equações do 2º Grau
A aplicação deve ter um campo para digitação da equação e um botão para iniciar o procedimento de cálculo.
Ao clicar no botão de cálculo, a aplicação deve:
	1 - Apresentar ao usuário um passo a passo da resolução, utilizando a fórmula de bhaskara.
	2 - Apresentar ao usuário o valor de delta, informar se a equação possui raízes reais e quais são as raízes.
	3 - Projetar um plano cartesiano e apresentar ao usuário o gráfico correspondente à equação, destacando as raízes reais, se houverem.

A aplicação deve ser desenvolvida no padrão Open API, com backend em Java e frontend em Node.js
	- Stack Java: Java 21, springboot 4.1.2
	- Stack Node.js: Node 26

Adicionar no frontend um seletor de modo claro e escuro no frontend, para melhorar a jornada de acessibilidade do usuário.

Gere também um manual do aplicação, explicando como o Resolvedor funciona, como utilizar suas funcionalidades, e como sua utilização contribui para o reforço no aprendizado de equações de 2º grau.
Disponibilize o manual no aplicativo nas versões em PDF e em HTML, para visualização rápida.

O manual deve ter as seguintes seções:
	1- Capa: Resolvedor de Equações do 2º Grau
	2- Como o Resolvedor Funciona
	3- Como Utilizar as Funcionalidades do Resolvedor
	4- Como o Resolvedor contribui para o Reforço no Aprendizado de Equações do 2º Grau
	5- Informações Técnicas: Arquitetura Tecnológica e Fluxo de Processamento Interno

Cada seção 2do manual deve começar em uma nova página.
