- **`typescript:S128` — Cláusulas 'case' de um 'switch' devem terminar com uma instrução 'break' incondicional** (`BLOCKER`): Deixar a execução vazar de um 'case' para o próximo (fallthrough) sem 'break', 'return' ou 'throw' quase sempre introduz bugs silenciosos. | ❌ `switch (x) { case 1: doOne(); case 2: doTwo(); break; }` → ✅ `switch (x) { case 1: doOne(); break; case 2: doTwo(); break; }`
- **`typescript:S1314` — Literais octais legados não devem ser utilizados** (`BLOCKER`): Números iniciados com zero (como '071') são interpretados como octais em modo não-estrito, o que confunde desenvolvedores. - **`typescript:S2068` — Credenciais fixadas no código (hardcoded) são sensíveis à segurança** (`BLOCKER`): Senhas e segredos atribuídos a variáveis contendo termos como 'password', 'pwd' ou 'passwd' no código-fonte podem ser comprometidos. Use cofres de segredos ou variáveis de ambiente. *(Params: `passwordWords=password, pwd, passwd`)* | ❌ `const password = 'SuperSecretPassword123!';` → ✅ `const password = process.env.DB_PASSWORD;`
