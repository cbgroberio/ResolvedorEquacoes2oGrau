# Guia Compacto SonarQube + Quality Gate — CSS

> **Perfil:** `backup` | **Regras:** `21` | **Legenda:** `❌ O que não fazer` → `✅ O que fazer`

## 🛡️ Métricas Obrigatórias do Quality Gate
- **`QG:DuplicatedLines` (`<= 3.0%`)** | **`QG:RatingsA` (`Nota A`, 0 Issues Blocker/Critical/Major e 0 Bugs/Vulns MINOR)** *(Cobertura de testes aplica-se apenas a JUnit e Jest)*

## 🔴 BLOCKER (Falha em `Blocker Issues > 0`) (5 regras)

- **`css:S4647` — Valores de cores hexadecimais devem ser válidos** (`BLOCKER`): Cores hexadecimais em CSS devem possuir exatamente 3, 4, 6 ou 8 dígitos hexadecimais válidos (0-9, a-f). | ❌ `.text { color: #12345; background: #ggg; }` → ✅ `.text { color: #123456; background: #fff; }`
- **`css:S4650` — Strings CSS não devem conter quebras de linha não escapadas** (`BLOCKER`): Strings literais em CSS não podem atravessar múltiplas linhas sem escape (\), pois geram erro de sintaxe. | ❌ `.icon::after { content: 'linha 1 linha 2'; }` → ✅ `.icon::after { content: 'linha 1\A linha 2'; }`
- **`css:S4653` — Expressões calc() não devem conter operadores sem espaçamento adequado ou vazias** (`BLOCKER`): Em calc(), operadores + e - exigem espaço em branco ao redor para não serem confundidos com sinais ou unidades. | ❌ `.col { width: calc(100%-20px); }` → ✅ `.col { width: calc(100% - 20px); }`
- **`css:S4654` — Propriedades CSS desconhecidas não devem ser utilizadas** (`BLOCKER`): Utilize apenas propriedades CSS válidas da especificação (exceções permitidas: composes, /^mso-/, seletores :export/:import). *(Params: `ignoreSelectors=/^:export.*/, /^:import.*/, ignoreTypes=composes, /^mso-/`)* | ❌ `.card { colr: #333; padding-vertical: 8px; }` → ✅ `.card { color: #333; padding-block: 8px; }`
- **`css:S4668` — Diretivas @import não devem aparecer após outras regras CSS** (`BLOCKER`): Pela especificação CSS, @import deve vir no início do arquivo antes de qualquer outra regra (exceto @charset/@layer), caso contrário é ignorado pelo navegador. | ❌ `.body { margin: 0; } @import 'reset.css';` → ✅ `@import 'reset.css'; .body { margin: 0; }`

## 🟠 CRITICAL (Falha em `Critical Issues > 0`) (3 regras)

- **`css:S4651` — Unidades de medida CSS devem ser válidas e reconhecidas** (`CRITICAL`): Não utilize unidades de medida inexistentes ou com erro de digitação (use px, rem, em, %, vh, vw, s, ms, etc.). | ❌ `.box { width: 100pix; transition: 200sec; }` → ✅ `.box { width: 100px; transition: 200ms; }`
- **`css:S4657` — Propriedades shorthand não devem sobrescrever propriedades mais específicas já declaradas** (`CRITICAL`): Declarar uma propriedade shorthand (ex: margin, background) após sua propriedade longhand (ex: margin-top) anula o valor específico anterior. | ❌ `.box { padding-top: 20px; padding: 10px; }` → ✅ `.box { padding: 10px; padding-top: 20px; }`
- **`css:S4670` — Seletores de tipo (tags HTML) desconhecidos não devem ser utilizados** (`CRITICAL`): Use apenas tags HTML/SVG válidas ou custom elements permitidos pelo perfil (custom-elements com hífen e prefixos /^(mat|md|fa)-/). *(Params: `ignore=custom-elements, ignoreTypes=/^(mat|md|fa)-/`)* | ❌ `divv { display: flex; }` → ✅ `div { display: flex; }`

## 🟡 MAJOR (Falha em `Major Issues > 0`) (13 regras)

- **`css:S125` — Trechos de código CSS comentados devem ser removidos** (`MAJOR`): Código CSS comentado polui o arquivo e reduz a legibilidade; utilize o controle de versão (Git) para histórico. | ❌ `.btn { /* background: #ccc; border: 1px solid red; */ color: #000; }` → ✅ `.btn { color: #000; }`
- **`css:S4648` — Listas de font-family devem terminar com uma família genérica** (`MAJOR`): Sempre inclua uma fonte genérica de fallback (sans-serif, serif, monospace) ao final de font-family caso a fonte principal não carregue. | ❌ `body { font-family: 'Roboto', 'Open Sans'; }` → ✅ `body { font-family: 'Roboto', 'Open Sans', sans-serif; }`
- **`css:S4649` — Funções linear-gradient() devem ter sintaxe e direção válidas** (`MAJOR`): Use a sintaxe padrão W3C em linear-gradient (ex: 'to bottom', '45deg'), evitando sintaxes antigas incompatíveis. | ❌ `.bg { background: linear-gradient(top, #fff, #000); }` → ✅ `.bg { background: linear-gradient(to bottom, #fff, #000); }`
- **`css:S4652` — Nomes de fontes em font-family não devem ser duplicados** (`MAJOR`): Não repita o mesmo nome de família tipográfica na mesma declaração font-family ou font. | ❌ `p { font-family: Arial, sans-serif, Arial; }` → ✅ `p { font-family: Arial, sans-serif; }`
- **`css:S4655` — A anotação !important não deve ser usada dentro de @keyframes** (`MAJOR`): Declarações !important dentro de blocos @keyframes são ignoradas pelos navegadores conforme a especificação CSS. | ❌ `@keyframes fade { from { opacity: 0 !important; } to { opacity: 1; } }` → ✅ `@keyframes fade { from { opacity: 0; } to { opacity: 1; } }`
- **`css:S4656` — Propriedades duplicadas não devem ocorrer no mesmo bloco de declaração** (`MAJOR`): Não declare a mesma propriedade duas vezes no mesmo seletor, pois a segunda sobrescreve a primeira (fallbacks legítimos são ignorados: ignoreFallbacks=true). *(Params: `ignoreFallbacks=true`)* | ❌ `.box { color: red; margin: 10px; color: blue; }` → ✅ `.box { margin: 10px; color: blue; }`
- **`css:S4658` — Blocos CSS vazios devem ser removidos** (`MAJOR`): Seletores ou regras @media/@keyframes com chaves vazias {} não têm efeito e devem ser removidos. | ❌ `.empty-card { }` → ✅ `.empty-card { display: block; }`
- **`css:S4659` — Pseudo-classes desconhecidas não devem ser utilizadas** (`MAJOR`): Use apenas pseudo-classes CSS padrão ou permitidas pelo perfil (:local, :global, :export, :import, :deep). *(Params: `ignorePseudoClasses=local,global,export,import,deep`)* | ❌ `a:hoverr { text-decoration: underline; }` → ✅ `a:hover { text-decoration: underline; }`
- **`css:S4660` — Pseudo-elementos desconhecidos não devem ser utilizados** (`MAJOR`): Use apenas pseudo-elementos válidos (::before, ::after, ::placeholder, etc.) ou permitidos (::ng-deep, ::v-deep, ::deep). *(Params: `ignorePseudoElements=ng-deep,v-deep,deep`)* | ❌ `p::first-lines { font-weight: bold; }` → ✅ `p::first-line { font-weight: bold; }`
- **`css:S4661` — Media features desconhecidas não devem ser usadas em @media** (`MAJOR`): Em consultas @media, utilize apenas recursos válidos como min-width, max-width, orientation, prefers-color-scheme. | ❌ `@media (max-widht: 768px) { .menu { display: none; } }` → ✅ `@media (max-width: 768px) { .menu { display: none; } }`
- **`css:S4662` — Diretivas @ (at-rules) desconhecidas não devem ser utilizadas** (`MAJOR`): Utilize apenas at-rules CSS válidas (@media, @keyframes, @import, @supports, @font-face) ou diretivas SCSS/Tailwind permitidas. *(Params: `ignoreAtRules=value,at-root,content,debug,each,else,error,for,function,if,include,mixin,return,warn,while,extend,use,forward,tailwind,apply,layer,container,/^@.*/`)* | ❌ `@medai (min-width: 600px) { .a { color: red; } }` → ✅ `@media (min-width: 600px) { .a { color: red; } }`
  - **Falso positivo sistêmico com Tailwind 4:** o `ignoreAtRules` do perfil não inclui `theme`, `custom-variant`, `utility`, `source`, `plugin` nem `variant`, diretivas exigidas por [`tailwind-4-tokens.md`](tailwind-4-tokens.md) e pelos `design-system.md`. Como a regra é `MAJOR`, cada ocorrência reprova o `QG:ZeroIssuesAndRatingsA`. Pedido ao time do Sonar: incluir essas at-rules no parâmetro. Até lá, cada ocorrência é marcada como falso positivo no servidor, pelo processo de [`sonar-frontend.md`](sonar-frontend.md) ("Notas da biblioteca"), sem supressão no código e sem trocar a diretiva.
- **`css:S4666` — Seletores duplicados não devem existir na mesma folha de estilo** (`MAJOR`): Consolide regras com o mesmo seletor em um único bloco CSS em vez de repetir o seletor várias vezes. | ❌ `.btn { color: #fff; } .btn { background: #0056b3; }` → ✅ `.btn { color: #fff; background: #0056b3; }`
- **`css:S4667` — Arquivos CSS não devem estar completamente vazios** (`MAJOR`): Não mantenha arquivos .css vazios ou contendo apenas espaços em branco no projeto. | ❌ `/* arquivo vazio sem regras */` → ✅ `:root { --primary-color: #004a8f; }`
